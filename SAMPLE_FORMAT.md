# Sample Quiz Format

This is an example of how your Word document should be formatted for the Canvas Exam Builder.

## Example Quiz

1. What is the capital of France?
a) London
b) Paris
c) Berlin
d) Madrid
Answer: b
Points: 1

2. Which planet is known as the Red Planet?
a) Venus
b) Mars
c) Jupiter
d) Saturn
Answer: b
Points: 2

3. What is 2 + 2?
a) 3
b) 4
c) 5
d) 6
Answer: b

4. The Earth is flat.
a) True
b) False
Answer: b
Points: 1

5. Who wrote "Romeo and Juliet"?
a) Charles Dickens
b) William Shakespeare
c) Mark Twain
d) Jane Austen
Answer: b
Points: 2

## Tips

- Each question should start with a number
- Use letters (a, b, c, d, etc.) for answer choices
- Always specify the correct answer with "Answer: [letter]"
- Points are optional (defaults to 1 if not specified)
- Questions can have 2-10 answer choices
